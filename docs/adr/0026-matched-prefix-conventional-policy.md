# ADR0026: Prospective matched-prefix conventional comparison

Status: COORDINATOR_DEFINED_PROSPECTIVE_POLICY; genuine scientific review and
exact source/access/prefit approvals remain pending. Date: 2026-10-01.

The owner authorized the continuation brief's matched-control and prefix studies.
ADR0021 supplies the temporal partition and original-DEV selection rules; ADR0025
supplies the separately registered CF control ancestry. Neither makes the
historical fixed-300-tree LightGBM run a prefix-adapted reference. This decision
defines that additional comparison before any new reserved numerical access.

Use the existing native reference feature function and quantile recipe without
feature search: H96; fifteen quantile/horizon boosters; at most 300 trees;
learning rate 0.03; 31 leaves; minimum child samples 64; column fraction 0.9;
L2 regularization 1.0; four CPU threads; seeds 7, 13 and 23. Freeze four original
AEON4 DEV iteration choices at 75, 150, 225 and 300. Select the earliest strict
improvement in native daily pinball using the existing daily floor of 18.
The native reference source hash is pinned in
`orchestration/native_prefix_matched_policy_v4.json`; each runtime policy adds
exactly one seed and binds its source/configuration bytes. Conventional fits
have tree iterations, not neural optimizer-update counts.

Every adapted arm receives the same permitted, deployment-specific prefix data
and observed labels. Keep H96, four source-day context warmup, 1/7/30 labelled
source-day prefixes, prefix-contained targets and the common suffix at source
day 41. Do not borrow future context, pool the two reserved deployments, fit
scalers on the prefix/suffix, change crop semantics in one arm, or select on
suffix outcomes. LightGBM retains its historical raw-dB feature/target scaling;
neural arms retain their original TRAIN scalers and all fitted ancestry.

Retain frozen pretrained, random and supervised CF feature alternatives with
fresh matched heads, plus fresh CF scratch. Preserve the neural 2000/500/64
recipe, original initialization and original-DEV selection. Persistence and
seasonal24 remain no-fit references. A DEV win over LightGBM is not a transfer
eligibility condition. Final artifact identities and adaptation rules must be
frozen before reserved outcomes.

These cells belong to the separate adaptation study. They do not rewrite the
original 43-neural/47-method campaign or the historical LightGBM result. Adapted
outputs remain explicitly non-zero-shot. Real execution remains NOT_RUN; this
ADR is neither a scientific approval nor evidence that the review service has
been restored. Aggregate/Band caps and the evaluation reserve remain unchanged.
