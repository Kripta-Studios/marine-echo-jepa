# ADR 0024: owner-authorized VLC desktop coexecution

Date: 2026-09-30. Status: prospective operational revision; distinct prefit required.

The owner explicitly instructed research to continue while VLC is open. The
original conservative WDDM ownership classifier omitted VLC from its fixed
desktop allowlist and therefore rejected direct seed13 before its first update.
That failed attempt, original classifier, fitted sources and prior approvals
remain unchanged; its 69.234 full-owned seconds remain charged.

Add a separately versioned operational classifier with one owner-authorized
desktop exception, `vlc.exe`, exclusively under WDDM and the exact bound owner
resolution. Unknown processes and other Python/ML runtimes continue to block.
The exception permits a desktop media application alongside one owned scientific
training tree; it does not permit a second scientific training process. No
foreign process is terminated. GPU hardware exclusivity remains unverifiable,
and VLC's consumption is unmeasured; the owner's description is not a metric.

Prospective additive executors may change only operational import/routing and
the corresponding reviewed source closure. Scientific objectives, architecture,
artifact schema, seeds, sampling, schedules, checkpoint selection, data,
scalers and fitted ancestry stay fixed. Preserve all historical source bytes.
Prove scientific AST equivalence and guard behavior, then obtain a distinct
prefit for the exact new source and command before CUDA execution. Do not
silently relax the original classifier or bypass it through monkeypatching,
process renaming, hidden GPU state or environment hooks.

The single-tree supervisor, strict allocated/reserved GPU memory below 10 GiB,
owned-tree RAM below 22 GiB, Band 12-hour allowance within 96 hours, full-attempt
failure accounting and exclusive owner lock remain mandatory. This revision
grants no cloud, paid, credential, filesystem permission or final-site access.
It does not retry the denied junction-removal command or change an app release.
