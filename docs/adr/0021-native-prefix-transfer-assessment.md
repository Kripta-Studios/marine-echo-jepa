# ADR 0021: Native prefix transfer assessment

Status: PROPOSED; no numerical final-site access or adaptation fitting authorized by this document alone.
Date: 2026-09-30.

The mission and ADR0015 require a 1/7/30-day adaptation curve when cohort support permits. This extension is separately versioned because whole-deployment exclusion in the zero-shot assessment intentionally rejects fitted ancestors from the assessed deployment. An adapted model is not zero-shot. Historical compatibility exposure remains disclosed.

Reserve boundaries using the already frozen source start dates, without inspecting acoustic values. For each reserved AEON2 deployment, allow four complete source-calendar days for the 96-interval context. Label-prefix day zero is midnight on the source start date plus four days. Prefix end is that midnight plus 1, 7 or 30 calendar days, exclusively. All fitted target timestamps must lie within that prefix; all fitted contexts must begin on or after the frozen source start date. Fitting can use the initial warmup observations and its prefix observations, never observations or targets after the prefix end. No SSL target crops are used for adaptation. Missing support cannot move these dates or select a more favourable prefix.

For every prefix length, assess the same later suffix. Its first issuance cutoff is midnight at the label-prefix start plus 30 days plus seven days; the suffix continues to the frozen source end. The seven-day gap exceeds history96 plus forecast6 source intervals. Prove exact context-observation and fitted-target interval identities are disjoint from every suffix context and target. Reject crossing deployment, configuration or interval discontinuities. Native primary geometry remains 0–230 m, with original 150/180-ping eligibility and source-date conventions; 165-ping values remain quarantined.

Adaptation reuses only previously selected TRAIN-only acoustic encoders. Create a fresh query head, rather than initialize from a trained forecast readout. Frozen SSL, non-JEPA, random and supervised features use the same head within each backbone size. Include a scratch supervised temporal model given exactly the same numerical prefix labels and masks. CF latent128/head18565 differs from the shared latent64/head5189; disclose this cross-architecture limitation. Use unchanged original TRAIN statistics for all feature/target scaling, with their fitted ancestry recorded. No new-site scaler fitting, zero-shot head inheritance or automatic label-saving claim is permitted.

Use fixed 2000 supervised updates, cadence500, batch64, AdamW peak LR0.0003, weight decay0.0001, clip1, 10% warmup and cosine decay to10% of peak. Every method has four scheduled development checkpoint opportunities under the same native daily pinball rule and floor18. Select on the original AEON4 development deployment only, not on AEON2 prefix or suffix outcomes. Report this external development selection and its additional data exposure explicitly. A future version could test within-deployment calibration, but this version does not add target-site calibration labels. Preserve the common seeded sample-index sequence, fresh-head initialization and actual prefix-label counts; repeated batches are not additional labels. Three finalist/direct seeds7/13/23 are mandatory; a control evaluated only at seed7 is labelled accordingly, never pooled as a three-seed result.

Require at least one admissible supervised prefix row per required horizon and at least one eligible floor18 suffix date per horizon/deployment. Insufficient support yields NOT_ASSESSABLE for that declared cell, without shrinking its support or changing its boundary. Save complete row-level forecasts, masks, dates, selected checkpoints, fit observation/target identities, recursive ancestry, actual resources and prefix counts. Keep seed variability separate from the predeclared 48-nominal-hour block uncertainty. Assess prefix comparisons jointly on the common suffix; never compare different suffixes to suggest a learning curve.

Before any real adaptation fit, a distinct prefit review must bind exact encoders, configurations, temporal partitions, fitted ancestry, source/reader code, supervisors, development data, targets and sample policy. The final-site numeric-access review must authorize this separately declared prefix/suffix use before the first unseal. The original 96-hour aggregate and one scientific-process ownership apply, including startup, evaluation, failures and saves. This is a predeclared transfer experiment, not a new architecture/configuration search. This proposal does not resolve ADR0020's pending owner clarification.

Software tests must independently demonstrate exact timestamp boundaries and raw-interval disjointness, prefix-only gradients and scaling ancestry, unchanged suffix masks/targets across lengths/methods, future-target perturbation invariance of inputs, deterministic matched batching and heads, fresh readout initialization, resume and protected writes. An independent scientific review must verify the actual fitted rows and reconstruction after execution.
