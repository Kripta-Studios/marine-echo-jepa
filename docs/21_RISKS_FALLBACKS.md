# Risks and predetermined fallback decisions

| Risk | Detect by | Response without changing the scientific story |
|---|---|---|
| D1 endpoint503/login/network | day1 bounded probe and manual access | authorized manual download or OOI inventory; preserve access report |
| Missing/unsupported AZFP calibration | first hourly file +config | inspect official Echopype support; use verified OOI calibration; no physical-unit fiction |
| OOI example too short | manifest calendar audit | acquire adjacent same deployment dates within cap; otherwise diagnostic only |
| One deployment/strong serial dependence | design review | within-deployment future claim, block statistics, explicit generalization limitation |
| Signal persistence dominates | strong B0/B1 | keep reference; JEPA negative is a legitimate result |
| Instrument changes correlate with time split | metadata change audit | report shift strata; do not erase inconvenient periods post hoc |
| Inferred environmental values wrong | field provenance | omit unverified covariates; don't call internal temperature water temperature |
| GPU unsupported/OOM | kernel/profile tests | verified official build or CPU demo; owner-authorized cloud after measurement |
| Too many model ideas | day7 scope review | drop P1, freeze declared configs; no hidden hyperparameter search |
| Native agent model unavailable | first bound spawn | record exact blocker; no silent substitute or fictional independence |
| Cloud overruns | paid+committed ledger | stop new paidjobsat400USD; reserve100USD; verify provider shutdown |
| Deadline before positive JEPA result | validation/final review | ship best baseline and honest comparison, not manufactured neural superiority |
| Last-minute scientific bug | final invariant tests | invalidate exposed test claim; preserve corrected result as post-hoc diagnostic |

P0 scientific incompleteness must be visible. An elegant synthetic demo is not a public-data
trained model. A downloaded archive alone is not a calibrated dataset. A calibrated dataset
alone is not a benchmark. A positive public benchmark alone is not customer business value.
